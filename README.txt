ОРБИТА: файлы для своего сайта
==============================

Что внутри
  index.html              игра целиком (то же, что в Claude, плюс подключение иконки и манифеста)
  manifest.webmanifest    название, цвета и иконки веб-приложения
  sw.js                   работа без интернета и напоминания
  icon-192.png, icon-512.png, icon-maskable-512.png   иконки для Android и Chrome
  apple-touch-icon.png    иконка для iPhone
  badge-96.png            маленький значок в уведомлениях

Как выложить
  1. Положи ВСЕ файлы в одну папку на хостинге с HTTPS
     (подойдут GitHub Pages, Netlify, Vercel, Cloudflare Pages: просто перетащи папку).
  2. Открой в manifest.webmanifest строку "https://ВАШ-САЙТ/manifest.webmanifest"
     и впиши настоящий адрес. Это нужно, чтобы на Android игра узнавала,
     что приложение уже установлено, даже когда ты открываешь её в браузере.
  3. Открой сайт на телефоне: подсказка по установке появится сама.

Как работает проверка установки
  • Запуск с иконки (iPhone и Android): подсказка не показывается никогда.
  • Android в Chrome: игра узнаёт об установке через сам Chrome
    и больше не показывает подсказку.
  • iPhone в Safari: Safari не даёт сайтам узнать, установлено ли приложение,
    поэтому в Safari подсказка будет появляться. С иконки — нет.

Напоминания
  • Android: в установленном приложении на главной есть кнопка «Включить напоминания».
    Телефон сам будит игру примерно раз в день, и если ты сегодня не играл,
    приходит уведомление вроде «Твой корабль заждался 🚀».
  • iPhone: Apple разрешает уведомления веб-приложениям только через push-сервер.
    Обработчик push уже есть в sw.js. Нужен сервер с ключами VAPID
    (например, бесплатный тариф OneSignal), который будет их отправлять.

Треки игроков
  Общая медиатека «От игроков» работает только в версии внутри Claude:
  она хранится на серверах Claude. На своём сайте этот раздел будет пустым,
  а всё остальное (медиатека, своя музыка, ангар, монеты) работает полностью.
